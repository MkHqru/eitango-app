# 英単語学習アプリ（塾向けデモ版）

塾の中学生向けの英単語学習アプリです。忘却曲線に合わせて「忘れかけたころに、もう一度出す」ことで、単語を確実に覚えられるようにします。

このリポジトリは、塾長に見せて導入の許可をもらうための**デモ版**です。データはブラウザの中（localStorage）に保存され、サーバーは使いません。

- 公開URL（GitHub Pages）：https://mkhqru.github.io/eitango-app/ （下の「GitHub Pages での公開手順」のあとに使えます）
- チェック用テストページ：https://mkhqru.github.io/eitango-app/tests.html

---

## アプリの概要

| 機能 | 内容 |
|---|---|
| 単語 | 20級・19級・18級の3つの級（各40語、合計120語）。例文はすべてオリジナル |
| 出題形式 | 英語 → 日本語（4択）／日本語 → 英語（入力）／例文穴埋め（入力）。3つは別々に管理 |
| 忘却曲線 | 間違えた単語は翌日、正解するたびに 3日後 → 7日後 → 14日後 → 30日後。30日後も正解したら「覚えた」 |
| 1日の量 | 復習の単語 → 新しい単語（1日10語まで）の順。1回10問まで |
| 級 | 最初は20級。今の級の40語を例文穴埋めで1回以上解くと合格テスト（40問・36問以上で合格）を受けられ、合格すると次の級へ |
| 先生画面 | 生徒ごとの進み具合（今の級・最後に学習した日・覚えた単語・今日の復習・正答率）、苦手な単語、パスワードリセット、生徒の追加・削除 |
| 個人情報 | 生徒の本名は持ちません。生徒は ID（juku001 など）だけで管理します |

### デモ用のアカウント

| ID | パスワード | 内容 |
|---|---|---|
| teacher | admin | 先生 |
| juku001 | 1234 | 約2か月、毎日続けている。18級まで進み、覚えた単語が多い |
| juku002 | 1234 | 最初だけやって、1週間止まっている（先生画面で赤く表示される） |
| juku003 | 1234 | 英→日は得意だが、日→英が苦手 |
| juku004 | 1234 | 平均的（19級） |
| juku005 | 1234 | 平均的（20級。合格テストに一度不合格） |

- どのアカウントも、はじめてのパスワード変更は済ませてあります（デモをすぐ始められるように）
- 先生が新しく追加した生徒（juku006 …）と、パスワードをリセットした生徒は、次のログインでパスワード変更画面が出ます
- サンプルの学習記録は、リセットした日を基準に作られます（juku001 は約2か月前から、ほかの4人は3週間前から今日まで）。いつ見せても「最後に学習した日」などが正しく見えます

## 使い方

### 生徒

1. ID とパスワードでログインします（はじめてのときはパスワードを変更します）
2. 生徒ホームで、今の級と「例文穴埋めで学習した語数（例：32 / 40）」を確認できます
3. 「今日の単語テスト」で、出題形式（英→日・日→英・例文穴埋め）を選んで「始める」を押します
   - 各形式に「今日の復習」「今日の新しい単語」「覚えた単語」の数が出ます
   - 1回10問まで。答えるたびに正解が表示され、「次へ」で進みます
   - 今日の分が終わると「✅ 今日の分は完了」と出ます
4. 今の級の40語を例文穴埋めで1回以上解くと、「◯級の合格テストを受ける」ボタンが押せるようになります
   - 40問の例文穴埋めで、36問以上正解すると合格して次の級に上がります
   - 不合格のときは、間違えた単語が表示されます。再挑戦は翌日からです

### 先生

1. `teacher` / `admin` でログインすると、先生ホームが出ます（生徒のIDでは開けません）
2. **生徒一覧**：生徒ごとに、今の級・最後に学習した日・正答率・覚えた単語・今日の復習の残りが出ます
   - 3日以上学習していない生徒（まだ一度も学習していない生徒も）は、赤いカードで表示されます
3. 生徒のカードをタップすると、その生徒の**苦手な単語**（不正解の多い順）を3つの出題形式ごとに見られます。ここで**パスワードのリセット**と**生徒の削除**ができます
4. **全体の苦手単語ランキング**：全生徒の不正解の合計が多い単語の上位10語（形式ごと）
5. 「＋ 生徒を追加」で、新しい生徒（juku006、juku007 …）を作れます。初期パスワードは 1234 です

### デモ用の機能（全画面の上に表示）

- **デモ日付と「+1日」「+3日」「+7日」**：日付を進めて、忘却曲線で単語が戻ってくる様子を見せられます
- **「今日に戻す」**：日付を今日に戻します。ただし、進めた日付で解いた記録は残るので、**デモをやり直すときは使わず、ログイン画面の「デモデータをリセット」を使ってください**
- **「デモデータをリセット」**（ログイン画面）：画面の中で確認したあと、すべてを最初の状態（サンプルの生徒5人と学習記録）に戻します。追加した生徒、変更したパスワード、デモ日付も元に戻ります

> デモ版のデータは、そのブラウザの中だけに保存されます。スマホとパソコンなど、別の端末では別々のデータになります。デモは1台の端末で通して行ってください。

## 本番化で必要なこと

### 1. ログインとデータ保存の置き換え

デモ版はブラウザの中（localStorage）にデータを保存しているため、端末ごとにデータが分かれ、パスワードも平文で保存しています。本番では次のどちらかのサービスに置き換えます。

| | Firebase | Supabase |
|---|---|---|
| ログイン | Firebase Authentication | Supabase Auth |
| データ保存 | Cloud Firestore | PostgreSQL（Supabase のデータベース） |
| アクセスのルール | Firestore セキュリティルール | Row Level Security（RLS） |

置き換えるところ：

- `js/storage.js`：データの保存先（今は localStorage）。アプリのデータの保存はすべてこのファイルを通しているので、ここを差し替えます
- `js/auth.js`：ログイン・パスワード変更・先生の操作。パスワードはサービス側で安全に管理されます（アプリでは持ちません）
- `js/date.js`：本番ではデモ用の日付操作（「+1日」など）を消し、`today()` は本当の今日だけを返すようにします
- `js/sample.js`：サンプルの学習記録はデモ専用なので、本番では使いません

#### 「先生だけが全生徒の記録を読める」ことを、データベースのルールでも守る

デモ版では、先生画面を開けるかどうかをブラウザの中（アプリのプログラム）だけで判定しています。本番では、アプリの画面を出さないだけでは不十分です。ブラウザのプログラムは利用者が書きかえられるので、**データベースのルール**で次を必ず守る必要があります。

- 生徒は、**自分の**学習記録だけを読み書きできる（ほかの生徒の記録は読めない）
- 先生（先生のアカウント）だけが、**全生徒の**学習記録を読める
- 生徒の追加・削除、パスワードのリセットは、先生だけができる

Firebase なら Firestore セキュリティルール、Supabase なら Row Level Security（RLS）で設定します。

### 2. 費用の目安

- **GitHub Pages**：公開リポジトリなら無料です
- **Firebase / Supabase**：どちらも無料プランがあり、塾1つ分（生徒数十〜100人程度）の利用なら無料の範囲に収まる見込みです。生徒数や利用量が増えたときは有料プランが必要になる場合があります
- 料金や無料の範囲は変わることがあるので、導入前に各サービスの公式の料金ページで確認してください

### 3. 個人情報の扱い

- 生徒の本名は保存しません。生徒は ID（juku001 など）だけで管理し、「ID と生徒の対応表」は塾の中で（アプリの外で）管理します
- 保存するのは、ID・パスワード（サービス側で管理）・学習記録・今の級だけです
- 保護者・生徒への説明（どんなデータを、何のために保存するか）と、プライバシーポリシーを用意します
- データの保存場所（国・地域）を、利用するサービスの設定で確認します
- 退塾した生徒のデータは、先生画面の「この生徒を削除」で消せるようにしています

## GitHub Pages での公開手順

このリポジトリは公開（Public）リポジトリなので、無料で GitHub Pages を使えます。

1. GitHub でこのリポジトリ（MkHqru/eitango-app）を開く
2. 上のメニューの **Settings** を開く
3. 左のメニューの **Pages** を開く
4. 「Build and deployment」の **Source** で **Deploy from a branch** を選ぶ
5. **Branch** で `main`、フォルダで `/ (root)` を選び、**Save** を押す
6. 数分待つと、同じ Pages の画面の上に公開URL（https://mkhqru.github.io/eitango-app/）が表示されます
7. スマホでそのURLを開き、ログイン → 生徒ホーム → テストまで動くことを確認します

- ビルドは不要です（HTML / CSS / JavaScript だけ）。`main` に変更をマージすると、数分で公開URLにも反映されます
- 公開リポジトリなので、プログラムは誰でも見られます。パスワードや API キーなどの秘密情報は、リポジトリに入れないでください（デモ用の 1234 / admin は、デモ専用の値です）
